# ADR-0008: Neutral framing; the helper is not told about the requester's limits

- Status: accepted, 2026-10-12
- Deciders: user

## Decision
The default framing is neutral (blueprint §16): nothing says a file is restricted on purpose. The helper agent is told nothing about other agents' grants. A "restricted on purpose" cue is a possible later condition, as text only.

## Consequences
v1 results support claims about help-seeking. They do not support claims about policy circumvention.
